# Telegram Bot для поиска свободных 5- и 6-значных юзернеймов

Этот бот помогает находить свободные имена в Telegram.

## Команды
- `/start` — начать работу с ботом
- Кнопки "5 знаков" и "6 знаков" для поиска

## Как запустить
1. Установите Python 3.10+
2. Установите библиотеку: `pip install -r requirements.txt`
3. Запустите бота: `python bot.py`
